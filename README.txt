Included:

- blog.html and blog/: blog index and posts
- styles.css: shared styling
- images/: supplied Beaverelle profile image and Hyalite water-budget charts

HOW TO PUBLISH ON GITHUB PAGES
1. Download and unzip this folder on your Mac.
2. Open your repository in a browser: https://github.com/hlndarlington-lang/hlndarlington-lang.github.io
3. Make sure you are signed in to the GitHub account that has write access.
4. Choose Add file > Upload files.
5. Open the unzipped soil-guide-website folder and drag its CONTENTS (including the blog and images folders) into the upload area.
6. Commit the changes to the main branch.
7. In the repository, open Settings > Pages. If Pages is enabled, check that it deploys from the main branch and the /(root) folder.
8. Visit https://hlndarlington-lang.github.io/ after GitHub Pages finishes publishing.

IMPORTANT
- Upload the contents of this folder, not the outer folder itself.
- Keep the folder names and file names unchanged so the links and images work.
- This version uses only static HTML and CSS. No special software or paid subscription is needed.
- The Hyalite report and Beaverelle image abbreviations have been preserved where definitions were not provided.
